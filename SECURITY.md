# Política de Seguridad

## Reportar una vulnerabilidad

**NO abras un issue público de GitHub para vulnerabilidades.**

Usá el reporte privado de seguridad de la organización:
**https://github.com/whale-solutions-org/security/advisories/new**

### Qué incluir
- Repositorio y rama afectada
- Descripción del problema y su impacto
- Pasos para reproducir (o PoC mínimo)
- Versiones/entornos afectados

### SLA
- Los reportes **privados** se triagean en **≤ 48 hs hábiles**.
- Los reportes que lleguen por otra vía se migran a un advisory y triagean igual.

## Versiones soportadas

| STEM | Estado |
|------|--------|
| Main / producción | Soporte activo |
| Staging | Soporte activo |
| Otras | Sin garantía |
